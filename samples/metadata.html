Korean Ceramics Record Normalization

TypeMetadata cleanup
InputPublic museum records
OutputNormalized table
UseCollection workflow
Demonstration dataset using verified National Museum of Korea and Metropolitan Museum of Art public records. It shows field normalization without replacing the institutions' original catalogue data.

Problem

Collection information often arrives in mixed formats: inconsistent titles, dimension strings, institution-specific classifications, compound accession numbers, and partial notes. A working collection sheet needs a predictable schema while keeping the source reversible.

Normalized schema

Record ID · Institution · Canonical Title · Culture/Dynasty · Date/Period · Material/Technique · Dimensions · Accession No. · Location/Department · Source URL · Research Note

Normalization choices

  • Preserve institutional titles and accession numbers.
  • Normalize dimension syntax without inventing missing measurements.
  • Separate material and technique concepts only when the source supports the distinction.
  • Do not infer provenance from findspot, credit line, or collection location.
  • Retain one source URL for every working row so the data remains auditable.
For a client collection, the same schema can be extended with acquisition date, current location, ownership history, condition, image filename, rights, bibliography, and internal notes.
